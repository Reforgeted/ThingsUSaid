# Things U Said 项目技术说明

## 项目定位

Things U Said 是一款 Android 原生个人事项管理应用，支持分组管理、便签/Todo 创建、提醒通知及桌面小组件。当前已完整实现核心功能，但 UI 交互体验与视觉精致度仍有较大提升空间，拟引入 Flutter 进行 UI 层重构优化。

## 技术栈

- **语言**: Kotlin 2.2.10
- **UI 框架**: Jetpack Compose (BOM 2026.02.01) + Material3
- **架构**: 单 Activity + Navigation Compose + MVVM（ViewModel + Repository + Room）
- **数据层**: Room 2.7.1（4 张表：categories、notes、widget_configs、app_settings），KSP 编译，Flow 驱动响应式更新
- **桌面小组件**: Glance 1.1.1，通过 Room Flow 实现跨进程实时刷新，支持多实例绑定不同分组
- **提醒系统**: WorkManager 调度 + BroadcastReceiver（开机重调度 + 稍后提醒）
- **其他**: 无 DI 框架（手动依赖），compileSdk 36，minSdk 29

## 已实现功能

1. **分组管理**：增删改、10 色预设、长按拖动排序（自定义 ReorderableLazyColumn）
2. **便签/Todo**：标题+内容编辑、Todo 勾选完成、左滑完成/右滑删除（SwipeToDismissBox）、拖动排序
3. **折叠式时间选择器**：自定义 WheelPicker 滚轮组件（支持惯性滚动 + exponentialDecay 衰减 + spring 吸附），三列选择日期/时/分
4. **桌面小组件**：Glance 实现，支持背景透明度/字体大小实时调节、Todo 勾选、点击跳转对应分组、LazyColumn 自适应条目数
5. **提醒通知**：WorkManager 精确调度，通知显示便签内容，支持稍后提醒（可配间隔）
6. **设置页**：稍后提醒间隔、小组件透明度滑块、字体大小三档

## 当前 UI/交互痛点

1. **Compose 自定义组件开发成本高**：WheelPicker、ReorderableLazyColumn 等交互组件需从手势层手动实现，代码量大且调优困难
2. **Glance 小组件能力受限**：Glance 仅支持有限 Compose 子集，无法使用自定义布局、动画、复杂手势，样式调整空间小
3. **动画与视觉一致性不足**：页面转场、列表动画、微交互等缺乏统一设计语言，与主流 App 视觉品质有差距
4. **跨端扩展性为零**：纯 Android 原生方案无法复用到 iOS

## 数据模型概要

- **Category**: id, name, colorHex, createdAt, sortOrder
- **Note**: id, categoryId(FK CASCADE), title, content, isTodo, isCompleted, createdAt, updatedAt, dueDate?, reminderTime?, sortOrder
- **WidgetConfig**: appWidgetId(PK), boundCategoryId
- **AppSetting**: key(PK), value

数据库当前版本 4，含 3 次迁移（v1→v2 dueDate/reminderTime，v2→v3 app_settings，v3→v4 sortOrder）。

## 期望优化方向

1. **Flutter 重构 UI 层**：利用 Flutter 丰富的组件库和动画体系，提升滚轮选择器、拖动排序、滑动操作等交互体验
2. **小组件方案**：探索 Flutter Widget 或混合方案替代 Glance，突破当前渲染限制
3. **跨端复用**：为未来 iOS 版本提供 UI 层复用基础
4. **数据层保留**：Room 数据库、Repository、ViewModel 等数据/业务层尽量保留，仅替换 UI 渲染层
