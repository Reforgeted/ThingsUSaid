## 📌 阶段 1：基础设施与 App 核心逻辑（打好地基）

- **核心任务**：构建 Room 数据库，完成 App 内“分组管理”、“便签/Todo 列表”的增删改查。
- **测试标准**：App 打开后，能正常创建“生活”、“想法”分组，并在各分组下成功添加便签。

## 📌 阶段 2：Glance 桌面小组件首航（攻克核心）

- **核心任务**：引入 Jetpack Glance，编写第一个静态/动态列表的小组件（如 Todo 列表）。
- **测试标准**：小组件能成功拖到桌面上，并显示 App 内的所有 Todo 数据。

## 📌 阶段 3：多实例配置与分组绑定（产生质变）

- **核心任务**：实现“一个小组件实例绑定一个分组”。当添加小组件时弹窗让用户选择分组，并将 `appWidgetId` 与 `categoryId` 绑定持久化。
- **测试标准**：桌面上同时存在组件 A（只显示生活）和组件 B（只显示想法）。

## 📌 阶段 4：UI 跃升与动态进化（精细抛光）

- **核心任务**：引入 Material You 动态配色（跟随系统壁纸变色）；在小组件内实现点击“直接勾选完成 Todo”的快捷操作。
- **测试标准**：切换手机壁纸时小组件自动变色，点击小组件内的打钩按钮列表即时刷新。

## 1. 数据库架构设计 (Room Database)

为了完美支持小组件的按分组筛选，我们需要维护三张表：`categories`（分组）、`notes`（便签）以及 `widget_config`（小组件绑定关系表）。

## 📄 数据模型 (Entities)

```kotlin
package com.example.todoapp.data

import androidx.room.*

// 1. 分组表
@Entity(tableName = "categories")
data class Category(
    @PrimaryKey(autoGenerate = true) val categoryId: Long = 0,
    val name: String,
    val colorHex: String // 用于 UI 显示的主题色
)

// 2. 便签表 (带外键约束)
@Entity(
    tableName = "notes",
    foreignKeys = [
        ForeignKey(
            entity = Category::class,
            parentColumns = ["categoryId"],
            childColumns = ["categoryId"],
            onDelete = ForeignKey.CASCADE // 删除分组，级联删除便签
        )
    ],
    indices = [Index("categoryId")]
)
data class Note(
    @PrimaryKey(autoGenerate = true) val noteId: Long = 0,
    val categoryId: Long, // 外键，归属于哪个分组
    val title: String,
    val content: String,
    val isTodo: Boolean = false, // true 为待办事项，false 为纯便签
    val isCompleted: Boolean = false, // Todo 是否完成
    val createdAt: Long = System.currentTimeMillis()
)

// 3. 小组件配置表（核心：记录哪个桌面小组件绑定了哪个分组）
@Entity(tableName = "widget_configs")
data class WidgetConfig(
    @PrimaryKey val appWidgetId: Int, // 桌面小组件的唯一 ID
    val boundCategoryId: Long         // 绑定的小组件分组 ID
)
```

## 接口定义 (DAO)

```kotlin
package com.example.todoapp.data

import androidx.room.*
import kotlinx.coroutines.flow.Flow

@Dao
interface AppDao {
    // --- 分组操作 ---
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun insertCategory(category: Category): Long

    @Query("SELECT * FROM categories")
    fun getAllCategoriesFlow(): Flow<List<Category>> // 使用 Flow 实现 UI 数据实时自动刷新

    // --- 便签/Todo 操作 ---
    @Insert
    suspend fun insertNote(note: Note)

    @Update
    suspend fun updateNote(note: Note)

    // 核心：供小组件或 App 根据分组 ID 筛选数据
    @Query("SELECT * FROM notes WHERE categoryId = :catId ORDER BY createdAt DESC")
    suspend fun getNotesByCategoryId(catId: Long): List<Note>

    // --- 小组件配置操作 ---
    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun saveWidgetConfig(config: WidgetConfig)

    @Query("SELECT * FROM widget_configs WHERE appWidgetId = :widgetId")
    suspend fun getWidgetConfig(widgetId: Int): WidgetConfig?
}
```

## 2. 桌面小组件多实例核心逻辑设计 (Glance + Configuration)

为了实现小组件多实例各自独立，整体业务时序设计如下：

```unset
[用户在桌面添加小组件] 
       │
       ▼
[系统启动 WidgetConfigActivity] (弹出分组选择列表)
       │
       ▼
[用户选择“生活”分组] ──> [保存 (appWidgetId, 101) 到数据库]
       │
       ▼
[触发 GlanceWidget 刷新] ──> [读取配置得知绑定了 101] ──> [去 Note 表查 101 的数据] ──> [渲染桌面]
```

## 🛠️ Glance 小组件核心类伪代码

使用 **Jetpack Glance**，小组件的布局变得像写普通 UI 一样简单灵活：

```kotlin
package com.example.todoapp.widget

import android.content.Context
import androidx.compose.runtime.Composable
import androidx.glance.GlanceId
import androidx.glance.appwidget.GlanceAppWidget
import androidx.glance.appwidget.provideContent
import androidx.glance.layout.*
import androidx.glance.text.Text
import com.example.todoapp.data.AppDatabase
import androidx.glance.appwidget.glanceId

class TodoGlanceWidget : GlanceAppWidget() {

    override suspend fun provideContent(context: Context, id: GlanceId) {
        // 1. 获取当前小组件的原生 android 物理 ID
        val matrixId = (id as? androidx.glance.appwidget.AndroidRemoteViewsGlanceId)?.appWidgetId ?: return
        
        // 2. 从数据库获取该小组件绑定的分组
        val db = AppDatabase.getInstance(context).appDao()
        val config = db.getWidgetConfig(matrixId)
        val categoryId = config?.boundCategoryId ?: -1L

        // 3. 根据分组 ID 查询对应的便签数据
        val notesList = if (categoryId != -1L) db.getNotesByCategoryId(categoryId) else emptyList()

        // 4. 使用类似 Compose 的声明式语法直接渲染小组件 UI
        provideContent {
            Column(modifier = GlanceModifier.fillMaxSize().padding(8.dp)) {
                Text(text = "当前分组便签数: ${notesList.size}")
                // 这里后续可以让 AI 帮你生成更高级的 LazyColumn 滚动列表布局
            }
        }
    }
}
```

## 🎨 资源拉取与应用闭环

| 资源类型         | 业界优质获取渠道                | 如何无缝引入到项目中                                         |
| :--------------- | :------------------------------ | :----------------------------------------------------------- |
| **图标 (Icons)** | Google Material Symbols         | 在 Compose 中直接使用官方扩展库 `androidx.compose.material:material-icons-extended`，无需手动下载 SVG，数万个图标直接通过代码调用（如 `Icons.Default.Notes`）。 |
| **动态配色**     | Material Theme Builder 线上工具 | 1. 在工具中选好主色调。 2. 导出为 **Jetpack Compose (Kotlin)** 格式。 3. 会得到 `Color.kt` 和 `Theme.kt`，直接丢进项目覆盖，App 就能一键获得大厂级高质感色彩体系。 |
| **视觉灵感**     | Dribbble 社区                   | 搜索 `Android Widget Material 3`。看到好看的卡片（带平滑圆角、微弱阴影和玻璃拟态），直接把图片发给 AI，对 AI 说：*“请帮我用 Jetpack Compose / Glance 实现这个卡片的视觉效果”*。 |
